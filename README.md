# RuGram Fragment

Собственный маркет номеров в стиле Fragment для self-hosted RuGram. Юзернеймов как актива **не существует** — только номера `+7` и `+888`.

> Это демо-проект для своего сервера. Он не связан с Telegram или Fragment и не принимает реальные платежи. Все операции идут во внутренней валюте demо — gram.

## Что умеет

- **Выбор префикса ползунком:** `+7` или `+888`. Каталог и цены перестраиваются мгновенно.
- **Пропорции номера:** каждый номер показывает состав цифр (цветная диаграмма), уникальность, повторы, зеркало, последовательности и оценку редкости 0–100.
- **Рулетка +888:** за 10 gram крутится барабан и выпадает случайный свободный номер `+888`. Каждый выпад сразу выставлен на продажу минимум за 3000 gram, хранилище номеров пополняется автоматически. Шансы зафиксированы: Обычный 3000 gram — 70%, Редкий 6000 gram — 25%, Особый 15000 gram — 4%, Легендарный 30000 gram — 1%.
- **Покупка навсегда:** номер закрепляется за аккаунтом в таблицах RuGram.
- **Продажа:** выставь свой номер по своей цене или сними с продажи.
- **Аукцион:** стартовая цена, длительность 24 часа, ставки, автоматический расчёт после окончания.
- **Кошелёк:** баланс gram из `ton_balances`, баланс звёзд из `stars_balances`.
- **Обмен звёзд → gram:** вызывается прямо из веб-клиента RuGram (кнопка в окне звёзд). 5000 звёзд = 1 gram.
- **Демо-пополнение:** по секрету из `.env`, только для разработки.

## Запуск

Нужны Node.js 20+ и доступ к Postgres RuGram.

```powershell
cd C:\Users\max\Downloads\rugram-fragment
npm install
Copy-Item .env.example .env
# укажи FRAGMENT_DATABASE_URL и FRAGMENT_TOPUP_SECRET
npm start
```

Открой <http://127.0.0.1:2700>. Вход — номером RuGram и демо-кодом (`12345`).

Переменные окружения:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `FRAGMENT_PORT` | `2700` | Порт HTTP-сервера |
| `FRAGMENT_DATABASE_URL` | `RUGRAM_POSTGRES_DSN` | DSN Postgres RuGram |
| `FRAGMENT_DEV_CODE` | `RUGRAM_DEV_AUTH_CODE` или `12345` | Демо-код входа |
| `FRAGMENT_STARS_TO_GRAM_RATE` | `0.0002` | Gram за одну звезду (5000 звёзд = 1 gram) |
| `FRAGMENT_TOPUP_SECRET` | `change-me` | Секрет демо-пополнения |
| `FRAGMENT_SESSION_TTL_HOURS` | `24` | Время жизни сессии |

## API

- `GET /api/healthz` — проверка доступности
- `POST /api/auth/request`, `POST /api/auth/verify` — вход
- `GET /api/me` — профиль, балансы, мои номера
- `GET /api/numbers?prefix=7|888&q=` — каталог номеров
- `GET /api/auctions` — активные аукционы
- `GET /api/numbers/spin-odds` — зафиксированные шансы и минимальная цена продажи
- `POST /api/number/spin` — рулетка: 10 gram → случайный `+888` от 3000 gram при продаже
- `POST /api/number/:id/buy` — купить
- `POST /api/number/:id/sell` — выставить на продажу / снять
- `POST /api/number/:id/auction` — создать аукцион
- `POST /api/auction/:id/bid` — сделать ставку
- `POST /api/wallet/topup-stars` — обмен звёзд на gram (вызывается клиентом RuGram)
- `POST /api/dev/topup` — демо-пополнение

## Интеграция с клиентом RuGram

`rugram-serve.mjs` проксирует `/fragment-api/*` на этот сервис. В окне звёзд клиента есть кнопка «Обменять звёзды на gram»: она отправляет номер, демо-код и количество звёзд, после чего обновляет балансы.
